## 3. 时间线与流程

- 统一入口：[ceec.iguopin.com](https://ceec.iguopin.com)（国聘平台的中国能建专区），往年还设过「AI 专区」
- 流程：招聘宣传 → 简历筛选 → 线上 / 线下测评 → 线上线下面试 → 通知录用 → 签订合同。海外岗加英语口语环节
- 投递材料：简历、推荐表、成绩单、外语等级证、获奖和证书扫描件
- 网申时间：一种说法是 2026-08-31 至 **2026-10-30**，另一种是 2026-09 至 2027-06（待核实）。**稳妥起见按 10-30 前投完**
- 外语和年龄：培训机构说硕士普遍要求六级 425 分（雅思能不能替代，待核实）；硕士不超过 28 岁

## 4. AI 赋能切入点（面试可用）

- **工程报告生成与校审**：中国能建东北院搭了 DeepSeek 工作平台，能生成和校审工程报告 → 可以讲「设计规范库 + RAG」做条款级校审，以及报告模板化生成怎么控制幻觉
- **AI 自动制图和元件识别**：东北院把大模型和工程绘图软件做了接口联动，实现 AI 自动制图和元件识别 → 讲图纸里的元件检测（目标检测）加参数化出图，你用 Python 能很快做出原型
- **新型电力系统规划**：新能源、储能大量接入后，规划方案要跑很多场景 → 用机器学习代理模型加速方案比选，把几天的计算压到几小时
- **海外工程项目**：多语种合同、标书、进度文件很多 → 用大模型做多语言信息抽取和风险提示（能用上你的英语）

## 5. 为什么适合我

- **成都有西南电力设计院**，「四川 + 电力」两个偏好都对得上
- 2027 届全球校招**单列了「人工智能类」岗位大类**，AI 不是附属在 IT 运维下面的
- 旗下设计院已经在用 DeepSeek 做报告和制图，说明他们真的需要能把大模型落到工程文档里的人，这正是你「AI 应用 + Vibe Coding」的长项
- 有「国际业务类」岗位和海外项目，能用上雅思；做 EPC 大项目还能学到大型工程的管理流程，对以后创业有帮助
- 招 5000 多人、岗位 1200 多个，可达性比国网统招高
