## 4. AI 赋能切入点（面试可用）

- **楼宇和数据中心能耗优化**：设备多、工况复杂、人工调参慢 → 用时序预测加强化学习做 AI 节能调度
- **配电设备预测性维护**：故障停机损失大 → 用传感器数据做异常检测和剩余寿命预测
- **工厂质检**：人工目检又慢又漏 → 用机器视觉做缺陷检测（对应上面的 AI开发实习生岗）
- **企业知识助手**：产品手册和工程文档很多 → 用 RAG 做技术支持 Agent

## 5. 为什么适合我

- [DEEPBLUE RIG](https://deepblue-rig.vercel.app/) 做的「设备健康状态实时监测」，就是施耐德配电设备预测性维护的同类问题；[商大元境 CampusTwin X](http://121.43.80.231/campus/)（校园三维孪生 + 自然语言接口）和 [会议室预约虾](https://zjgsu-y1k4.vercel.app/)（空间孪生 + Agent）对得上施耐德的楼宇能效和空间管理业务
- [智港 · 数字员工协同平台](https://smart-port-omega.vercel.app/) 里 5 个数字员工智能体协商审批，对上「AI解决方案设计」「AI工具开发」岗：把一个行业流程拆成多个 Agent 协作
- 「AI 咨询」「AI-PMO」岗能看到能源管理行业的项目是怎么立项、怎么推进的，正好满足你「体验行业内部怎么运转」的目的，也给读博选题和以后创业积累素材
- 外企环境，可以用英语，节奏相对友好，不用太有压力
