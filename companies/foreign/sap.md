## 3. 时间线与流程

- iXp 全年都在招，岗位随时上线下线，**建议每两周看一次**
- STAR 2028 届岗位已经上线（截至 2026-10-07），截止日没查到（待核实）。2028 届的话尽早投，不要等到 2027 年春季
- 流程一般是网申、技术面试（编程和项目深挖）、经理面试，具体以通知为准（待核实）

## 4. AI 赋能切入点（面试可用）

- **财务和采购流程自动化**：发票、对账、审批高度重复 → 用 LLM 做文档理解，再用 Agent 自动走流程
- **制造业 ERP 数据问答**：业务人员不会写 SQL → 用 GraphRAG 或 Text-to-SQL 让业务人员用自然语言查数据
- **供应链预测**：需求波动大 → 用时序预测给出补货和排产建议

## 5. 为什么适合我

- 「Full Stack AI-Native Developer」的 JD 明确写了**每天使用 AI 编程助手**，「Generative AI Developer」的 JD 更是直接把 **Vibe Coding（Claude Code、Codex）** 写进了要求，和你的习惯**完全对口**
- 你擅长 Java 和 Python，SAP 的技术栈正好以这两种语言为主
- 能学到大企业怎么组织财务、采购、生产的**完整业务流程**，以后做 To B 创业时很有用

## 6. 投递建议

- 英文简历必备，JD 全是英文
- 作品集里放一个「Vibe Coding 很快做出来的全栈 AI 应用」，最好有在线 Demo 和 GitHub 链接
- 时长是硬门槛：至少 6 个月、每周 3 天以上。**投之前先规划好到岗时间**
