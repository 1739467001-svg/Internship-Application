## 4. AI 赋能切入点（面试可用）

- **财务和采购流程自动化**：发票、对账、审批高度重复 → 用 LLM 做文档理解，再用 Agent 自动走流程
- **制造业 ERP 数据问答**：业务人员不会写 SQL → 用 GraphRAG 或 Text-to-SQL 让业务人员用自然语言查数据
- **供应链预测**：需求波动大 → 用时序预测给出补货和排产建议

## 5. 为什么适合我

- **Vibe Coding 直接写进了 JD**：「Generative AI Developer」要求熟练用 Claude Code、Codex 做 AI 辅助开发，还要做 RAG、Agentic workflows、MCP。你的 8 个作品全部在线，都是这样快速做出来的，这是最硬的证明
- **[智港 · 数字员工协同平台](https://smart-port-omega.vercel.app/)** 里，单证、配载、安全、调度、执行 5 个数字员工智能体协商审批，本质就是「业务流程 + Agent 自动走审批」，和 SAP 把 AI Agent 嵌进 ERP 流程的方向一致
- **[CJY 小票机](http://121.43.80.231/cjy/)** 做的是 RAG + 来源可溯源，对应 SAP 财务场景里「票据、单据理解，答案要能追溯到原始凭证」的要求
- ERP 连着制造、能源、零售这些行业的财务、采购、生产流程，在 SAP 实习等于一次看清很多行业的「后台」怎么运转，正好是你想体验的东西
- 你本科学软件工程，擅长 Java 和 Python，SAP 的技术栈正好以这两种语言为主
