## 4. AI 赋能切入点（面试可用）

- **企业 Agent 集成**：工厂的 ERP、MES、工单系统各自独立 → 用 LLM Agent 跨系统查询、自动生成工单
- **配电设备运维助手**：现场工程师查手册慢 → RAG 加语音问答
- **生产数据看板**：数据分散 → 统一数据管道，再用 AI 做异常预警

## 5. 为什么适合我

- [DEEPBLUE RIG](https://deepblue-rig.vercel.app/) 做的是海上钻井平台的设备健康实时监测，和 ABB 配电、电气化设备的状态监测、预测性维护是同一类问题
- [智港 · 数字员工协同平台](https://smart-port-omega.vercel.app/) 里 5 个数字员工智能体协商审批，就是「把企业业务系统和 LLM Agent 接起来」，对上 ABB 杭州那类 Agent 岗（Python + Java + LLM + Agent 框架）
- 厦门「研发 AI 实习生」要跟踪评测 AI 工具、找场景、做试点、写 SOP。你给浙江医药做过 HR AI Agent 智能体搭建培训，给浙江省青年创业协会做过 AI 培训，正好有「把 AI 工具教会业务部门」的经验
- 在电气化巨头实习，能看到一家传统工业企业怎么评估、试点、推广 AI，这正是你想体验的「行业内部怎么运转」
- 本科软件工程，Python 和 Java 都熟，英语工作环境也能用上你的雅思

## 6. 投递建议
