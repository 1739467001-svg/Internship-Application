## 4. AI 赋能切入点（面试可用）

- **AOI 视觉质检**：PCB 和零部件缺陷靠人工复判 → 视觉模型加主动学习，降低误判
- **工厂排产和预测性维护**：设备停机损失大 → 混合建模，把机理和数据结合起来
- **智能座舱 Agent**：车内语音助手只能做固定指令 → 用大模型 Agent 理解复杂意图

## 5. 为什么适合我

- 「AI 赋能学员」做的就是「AI 改造传统制造」，对应 Slogan 4️⃣「AI 必须扎根于场景」
- **JMP 预备役**偏管理和轮岗，适合你「学管理经验、以后创业」的目标
- 「AI and Web Backend Development Intern」要把 LLM 接进 Web 应用，正好用上你的 Java / Python 后端和 Vibe Coding 快速出原型的能力

## 6. 投递建议

- 实习普遍要求连续 4–6 个月。先算好自己在国内能待多久
- 简历上把「AI 应用项目」写成「场景、痛点、方案、效果」的结构
