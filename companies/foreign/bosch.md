## 4. AI 赋能切入点（面试可用）

- **AOI 视觉质检**：PCB 和零部件缺陷靠人工复判 → 视觉模型加主动学习，降低误判
- **工厂排产和预测性维护**：设备停机损失大 → 混合建模，把机理和数据结合起来
- **智能座舱 Agent**：车内语音助手只能做固定指令 → 用大模型 Agent 理解复杂意图

## 5. 为什么适合我

- [DEEPBLUE RIG](https://deepblue-rig.vercel.app/) 做的设备健康实时监测，对上博世工厂的预测性维护；[天府 TWIN](http://aerotwin-tfu.vercel.app/) 的调度算法 A/B 影子仿真和多指标评估，对上工厂排产优化的评估方法
- 「AI and Web Backend Development Intern」要把 LLM 接进 Web 应用。你的 8 个作品都是已上线的 Web 应用，比如 [会议室预约虾](https://zjgsu-y1k4.vercel.app/)（空间孪生 + Agent），这就是现成的证明
- 博世有专门的「制造 + AI 赋能」路线，能看到汽车和制造业的现场怎么用 AI，对应 Slogan 4️⃣「AI 必须扎根于场景」
- JMP 未来领军人偏管理和轮岗。就算不签约，了解它的培养方式，也能帮你看懂大公司怎么培养管理者
