## 2. 推荐岗位

| 岗位名称 | 方向 | 地点 | 关键要求 |
| --- | --- | --- | --- |
| Software Engineer Intern | 产品研发 | 北京 / 上海 / 苏州 | 本科或硕士在读，实习后至少还剩 1 个学期；1 年面向对象编程经验；数据结构和算法 |
| Cloud Solution Architecture Intern（MCAPS） | 帮企业客户做云和 AI 方案 | 北京 / 上海 / 深圳 | 面向海内外应届生 |
| Solution Engineering Intern（MCAPS） | 售前和技术方案 | 同上 | 同上 |

## 3. 时间线与流程

- 12 周的暑期项目**正好对上英国暑假**，是外企里时间最友好的一个
- 2027 年 1 月开始关注 careers.microsoft.com，提前准备算法题（LeetCode）

## 4. AI 赋能切入点（面试可用）

- **Azure OpenAI 给制造和能源企业落地**：企业想用大模型，但担心数据安全 → 私有化部署加 RAG 加权限管理
- **Copilot 进企业流程**：Office 和 Teams 里的流程自动化

## 5. 为什么适合我

- Java 和面向对象功底能直接用上，12 周时长适合留学生
- MCAPS 的解决方案岗能接触到大量传统行业客户，学**大客户销售和方案流程**

## 6. 投递建议

- 算法面试是硬门槛，从现在开始每周刷题
- MCAPS 岗位英语面试比重大，可以用你的雅思优势
