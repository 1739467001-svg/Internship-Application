## 3. 时间线与流程

- **关键日期**：2026-08-03 网申启动 → **2026-11-30** 网申截止（待核实）。实习生全年开放
- 流程：网申或内推 → 简历筛选 → 测评 → 部分岗位 **AI 面试**或在线笔试 → 面试 → 录用函。今年是京东首次在校招里用 AI 面试
- 入口：[campus.jd.com](https://campus.jd.com/) → 完善简历 →「招聘职位」→ 选对应项目；也可以找京东在职员工要内推码

## 4. AI 赋能切入点（面试可用）

- **工业品采购（京东工业）**：工业品 SKU 多、描述不规范，企业采购选型靠人工比对 → 用大模型做商品信息标准化、智能选型和询比价 Agent。京东工业说 JoyIndustrial 正在从「AI 工具」走向「AI 专家」
- **库存和补货**：制造业客户的备件库存要么积压、要么缺货 → 需求预测加补货优化
- **物流调度**：仓配路径和运力安排复杂 → 预测加优化调度
- **企业客服和知识库**：工业品售后问题专业性强 → RAG 加工单系统，做技术支持助手

## 5. 为什么适合我

- **Java 是主场**：第三方面经说京东的大模型岗离不开交易、库存、供应链、客服这些业务系统，看重 Java / Go / Python 工程能力（待核实）。你最擅长的两门语言都能用上
- **京东工业 = AI × 制造业**：服务的是传统企业的采购和供应链，和你「把 AI 用到传统行业」的定位一致，也能接上以后投电网、能源央企时讲的「供应链数字化」
- **实习生全年开放**：如果你算 2028 届，这是现在就能投的大厂之一
- **AI 面试**：你习惯和 AI 协作，可以先用 AI 模拟面试多练几轮
- **对创业有帮助**：京东同时有零售、物流、工业、科技几条线，在这里能看清楚一家公司怎么把技术、供应链和商业连起来

## 6. 投递建议

- 2027 届：**11-30 前**投递，越早越好。技术类优先，再看京东工业、京东科技的岗位
- 2028 届：现在就投 JD YOUNG 实习生，选技术类或产品类
- 简历突出「Java 工程能力 + AI 应用落地」。准备一个「AI 帮企业处理采购或库存」的小 Demo，用 Vibe Coding 几天就能做出来，面试时直接演示
- AI 面试：提前练习对着镜头讲 STAR 结构的项目经历，控制在 2 分钟内
