# 字节跳动 / 火山引擎（ByteDance / Volcano Engine）

[← 公司库](../README.md) ｜ [← 本次搜索](../../searches/2026-10-06-first-full-scan.md)

> 一句话：**日常实习不限届别**，所有在校生都能投，对毕业年份还没确定的你最友好。火山引擎有单独的「**企业解决方案**」职类，是 AI 赋能行业客户的一线。

## 1. 项目概况

| 项目 | 状态 | 对象 | 说明 |

| 火山引擎 2027 届校招 | 🟢 进行中 | 同上 | 八大类：销售、**企业解决方案**、技术、产品等 |
| ByteIntern（转正实习） | 🔵/🔴 2026-03-06 启动，具体岗位各有截止日期 | 2027 届 | 7000 多个 Offer，转正率 50% 以上 |
| 2028 届 ByteIntern | 🟡 预计 2027 年 3 月（推断） | 2028 届 | — |

## 2. 推荐岗位

| 岗位名称 | 方向 | 说明 |
| --- | --- | --- |
| AI Agent 开发 / AI 全栈工程师 | Agent 应用 | 2027 校招新岗位 |
| 火山引擎「企业解决方案」类岗位 | 帮行业客户落地大模型 | 校招岗位的具体名称待核实 |
| ByteIntern Agent 研发方向实习 | Agent 研发 | 抖音 ByteIntern 列表里有 |
| 不推荐：Seed 大模型 | 偏研究 | 和你的方向不太匹配 |

## 3. 时间线与流程

- 根据简历和岗位的匹配度，**灵活决定要不要笔试**，面试随时安排
- 投递次数有限，**每一次都要选最匹配的岗位**，不要随便投

## 4. AI 赋能切入点（面试可用）

- **火山方舟加行业 Agent**：零售、汽车、金融、能源客户都想用大模型，但不知道从哪个场景切入 → 解决方案岗负责诊断场景、设计方案、做 POC
- **企业知识库**：用 RAG 加权限体系做内部智能助手

## 5. 为什么适合我

- 日常实习**不卡届别**，现在就能投
- 企业解决方案岗 = **懂技术，又能和客户谈业务**，适合以后创业的人

## 6. 投递建议

- 日常实习要求 3 个月以上，需要回国全职。可以考虑寒假加 gap，或者毕业前后的空档期
- 简历第一行就写「AI 应用落地」加「全栈快速交付」
