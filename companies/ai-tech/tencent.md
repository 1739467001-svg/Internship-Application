# 腾讯 / 腾讯云智（Tencent）

[← 公司库](../README.md) ｜ [← 本次搜索](../../searches/2026-10-06-first-full-scan.md)

> 一句话：**腾讯云智**专门做政务、医疗、能源、工业等「云与智慧产业」的行业方案，在西安、武汉、长沙、重庆等二线城市招人，竞争相对没那么激烈。

## 1. 项目概况

| 项目 | 状态 | 对象 | 说明 |
| --- | --- | --- | --- |
| **腾讯 2027 校园招聘**（全职） | 🟢 2026-08-11 启动 | 2026-01 至 2027-12 毕业 | 不设统一笔试，部分岗位有 AI 实践测评 |
| 腾讯 2026 实习生招聘 | 🔴 2026-03-06 启动，剩余岗位截止 2026-08-23（待核实） | 2026-09-01 至 2027-12-31 毕业 | 1 万多名实习生 |

> 「Pre 留学生日常实习」面向的是**还没出国**的学生，你已经在英国读书，大概率不适用。

## 2. 推荐岗位

| 岗位名称 | 方向 | 说明 |
| --- | --- | --- |
| **Agent 开发工程师** | 多 Agent 协作、任务规划、工具调用、记忆和推理链 | 2027 校招新设的独立岗位 |
| **AI 全栈工程师** | 全栈加 AI | 第三方解读称：熟练使用 Cursor、Claude Code 等 AI 编程工具是**必备**（待核实） |
| AI 应用工程师 / AI 产品经理 | AI 应用落地 | 2027 校招新岗位 |
| 腾讯云智：后台开发 / 技术产品 / 项目管理 | 政务、医疗、能源、工业等行业解决方案 | 西安、武汉、长沙、重庆、厦门 |

## 3. 时间线与流程

- 网申 → （部分岗位）笔试或 AI 实践测评 → 专业初试 → 专业复试 → HR 面
- 唯一投递入口是 [join.qq.com](https://join.qq.com/)；腾讯云智走 [join.tencent-cloud.com](https://join.tencent-cloud.com/)
- 可以找在职员工或校园大使拿「伯乐码」内推

## 4. AI 赋能切入点（面试可用）

- **政务 Agent**：办事流程复杂 → 智能导办，自动填表
- **医疗**：病历结构化，辅助医保审核
- **能源和工业**：设备知识库问答，巡检报告自动生成

## 5. 为什么适合我

- 「AI 全栈」岗明确要会用 AI 编程工具，**你的 Vibe Coding 就是核心竞争力**
- 腾讯云智做的就是「AI + 传统行业」的交付和产品，能学到 **To B 项目怎么管**

## 6. 投递建议

- 准备一个「多 Agent 协作」的小项目，放在 GitHub 上，写清楚架构图
- 二线城市的腾讯云智岗位，可以作为稳妥的选择
