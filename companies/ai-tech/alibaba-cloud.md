## 4. AI 赋能切入点（面试可用）

- 阿里云明确在招「**AI+X 复合型人才**」，看重 AI 和具体场景的结合
- **政企和能源客户**：云厂商的行业解决方案，是把 AI 送进传统行业的主渠道
- **Agent 工程化**：官方说法是「把大模型的不确定性转化为工程确定性」，面试时可以讲你怎么让 AI 应用**稳定可靠**
- **结合作品**：[智港](https://smart-port-omega.vercel.app/) 的「多个数字员工协商审批」，可以讲成阿里云给港口、物流客户做行业 Agent 的样板

## 5. 为什么适合我

- **智港对上 Agent 岗**：[智港 · 数字员工协同平台](https://smart-port-omega.vercel.app/) 用 5 个数字员工智能体（单证、配载、安全、调度、执行）协商审批，正好对上阿里云新设的 AI Agent 优化、Agent Infra 岗：多个 Agent 怎么稳定协作、出错怎么兜底
- **小票机对上「工程确定性」**：[CJY 小票机](http://121.43.80.231/cjy/) 做的是 RAG 加来源可溯源，对应阿里云「把大模型的不确定性转化为工程确定性」的说法，面试时可以讲你怎么让答案有据可查
- **AI Coding 考核**看「用 AI 拆解需求、识别缺陷、迭代优化」的过程。你 28 场黑客松从参赛者做到评委，限时交付是你的主场
- **人在杭州**：阿里云总部也在杭州，实习不用搬家，最适合「不紧张、不折腾」地体验大厂怎么运转
